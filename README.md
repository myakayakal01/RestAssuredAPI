# RestAssuredAPI

## Overview
This project demonstrates the use of the Rest-Assured library for testing RESTful APIs in Java. It includes a simple example of fetching a list of dog breeds from the Dog CEO API.

## Prerequisites
- Java 21
- Maven 3.8+
- Internet connection (to access the Dog CEO API)
